# منصة ثانوية الذاكرين النموذجية — السجل الذكي (2026 - 2027)

منصة تعليمية وإدارية متكاملة لإدارة الدرجات، الحضور، جدول الحصص، التقارير الرسمية، وبوابة ولي الأمر وفق ضوابط وزارة التربية العراقية، مع عزل برمجي كامل لدرجات كل مادة وصلاحيات متعددة للأدوار.

---

## المميزات الرئيسية

### 1. بوابة الدخول والصلاحيات (RBAC)
- **الإدارة (المدير):** صلاحية كاملة على الهيكل الدراسي، حسابات المدرسين، الضوابط، السجلات، والنسخ الاحتياطي (الرمز التجريبي الافتراضي: `0000`).
- **المدرس:** واجهة معزولة تعرض فقط المواد والشعب المعيّنة للمدرس (رموز تجريبية: `1010` لمادة الأحياء، `2020` للكيمياء والفيزياء).
- **ولي الأمر:** متابعة درجات وحضور وملاحظات الطالب عبر رمز الـ PIN (مثل `1111`) أو عدة أبناء معاً (مثل `1111, 2222`)، أو مباشرة عبر رابط مشاركة مشفّر (`#p=...`).

### 2. سجل الدرجات والاحتساب التلقائي
- **عزل درجات المواد (`gradesBySubject`):** تخزين مستقل لدرجات كل مادة وطالب لمنع أي تداخل بين المواد.
- **مرونة التقييم الفصلي:** تخصيص أشهر الفصل الأول والثاني وأقسام التقييم اليومي (الواجبات، التحضير، الكويز، النشاط أو أقسام مخصصة) مع تحويل مجموع اليومي تلقائياً من 100.
- **الرصد السريع (`QuickGradeModal`):** نافذة مخصصة لإدخال درجات اليومي والتحريري بسرعة عالية.
- **ضوابط وزارة التربية العراقية:**
  - احتساب معدل الفصل الأول، نصف السنة، معدل الفصل الثاني، السعي السنوي، والدرجة النهائية.
  - دعم حالات الغياب والمؤجل في امتحانات نصف السنة والنهائي.
  - احتساب تلقائي لـ **الإعفاء الفردي** (السعي `>= 90`) و**الإعفاء الكلي** (المعدل العام `>= 85` وأقل مادة `>= 75`) مع إمكانية تعديل الضوابط من الإعدادات.
  - ربط درجات المشاركة التفاعلية بالفصل الأول أو الثاني أو للعرض فقط.

### 3. إدارة الطلبة والحضور والجدول
- **إدارة الطلبة:** إضافة فردية أو استيراد جماعي من ملفات Excel / CSV / TXT وتصدير الجداول إلى `.xlsx`.
- **الحضور اليومي:** تسجيل الحضور (حاضر / غائب / متأخر) للشعبة حسب التاريخ مع خيار تحضير الكل بضغطة واحدة وإحصاءات فورية.
- **جدول الحصص الأسبوعي:** تنظيم حصص الأسبوع (الأحد إلى الخميس — 7 حصص يومياً) مع انتقال مباشر من الحصة إلى سجل الدرجات أو الحضور، ودعم الطباعة.

### 4. أدوات المدرس المتقدمة
- **عجلة المشاركة التفاعلية:** اختيار عشوائي للطلبة بالـ SVG مع إضافة نقاط المشاركة تلقائياً إلى سجل المادة.
- **الملاحظات السلوكية والتعليمية:** توثيق الملاحظات (إيجابية، تعليمية، تنبيه) وعرضها في التقارير وبوابة ولي الأمر.
- **مصمم أسئلة A4 الرسمية (`A4ExamDesigner`):** إعداد وتنسيق أوراق الامتحانات الرسمية بحجم A4 مع ترويسة المدرسة، أنواع أسئلة متعددة (اختيار من متعدد، صح/خطأ، فراغات، مقارنة، تعليل)، نموذج إجابة، وطباعة مباشرة.
- **تكامل Google Forms:** تسجيل الدخول بحساب Google عبر Firebase Auth لإنشاء اختبارات إلكترونية أو استيراد درجات الاستجابات وربطها تلقائياً بسجل الدرجات.

### 5. التقارير، النسخ الاحتياطي، والمزامنة
- **طباعة وتصدير:** تقارير فردية وشهادات درجات وطباعة كشوفات الشعبة بتنسيق A4 جاهز للطباعة.
- **بوابة ولي الأمر والمشاركة:** إنشاء روابط مشاركة مستقلة أو إرسال ملخص الدرجات عبر واتساب مباشرة.
- **النسخ الاحتياطي والمزامنة:** حفظ تلقائي في المتصفح (`localStorage`) مع دعم الترحيل من النسخة القديمة (`V6`)، تنزيل/استعادة `JSON`، تصدير أرشيف `HTML` مستقل، والمزامنة المباشرة (رفع/جلب) مع مستودع **GitHub**.

## التقنيات المستخدمة

- **الواجهة الأمامية:** React 19 + TypeScript + Vite 8
- **التنسيق:** Tailwind CSS v4 (مع دعم الوضع الليلي واللغة العربية `dir="rtl"`)
- **الأيقونات:** Lucide React
- **ملفات Excel:** SheetJS (`xlsx`)
- **المصادقة والتكامل:** Firebase Auth (Google Workspace / Google Forms API)
- **الاختبارات:** Node.js Test Runner (`node:test`) عبر `tsx`

## التشغيل والتطوير محلياً

تأكد من توفر **Node.js** (الإصدار 18 أو أحدث)، ثم نفّذ الأوامر التالية في مجلد الجذر:

```bash
# 1. تثبيت الاعتماديات
npm install

# 2. تشغيل خادم التطوير على المنفذ 3000
npm run dev
```

سيعمل التطبيق على الرابط: `http://localhost:3000`
*(لتجاوز شاشة القفل والدخول السريع بحساب الإدارة أثناء التطوير يمكنك فتح `?autostart=1`)*.

### أوامر إضافية

```bash
# فحص الأنواع (TypeScript Check)
npm run lint

# بناء نسخة الإنتاج في مجلد dist/
npm run build

# معاينة نسخة الإنتاج
npm run preview
```

### تشغيل الاختبارات الوحدوية (Unit Tests)

```bash
npx --yes tsx --test src/utils/evaluation.test.ts src/utils/a4Exam.test.ts src/utils/googleForms.test.ts
```
